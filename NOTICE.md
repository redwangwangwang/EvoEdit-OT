# Attribution

EvoEdit-OT is derived from **BiOTPrompt: Bidirectional Optimal Transport Guided Prompting for Disease Evolution-aware Report Generation** by TengfeiLiu966 and contributors.

The upstream implementation is pinned as a git submodule at commit `b4955a22b5b157fc830c9734e8fbc801ab53ac7f`. BiOTPrompt itself contains code derived from R2GenGPT. The original BSD 3-Clause license is retained in `LICENSE`.

The EvoEdit-OT additions are model-side research code: birth--death unbalanced optimal transport, continuous evolution tokens, latent finding-slot encoding, transport-conditioned report editing, text-UOT edit distillation, and temporal inversion consistency.
